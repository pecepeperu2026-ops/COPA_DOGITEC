# COPA DOGITEC

Animación de la **COPA DOGITECH**: cinco equipos, todos contra todos, y **RRHH – Administrativos** campeón, con relator y ambiente de estadio.

Las fotos, voces y video están **cifrados** (AES-256-GCM) en `data/`. Solo se ven con el enlace completo que incluye la clave (`#k=...`), que no está en este repositorio.
